# 同一班期在報名通知與開課通知使用兩個顯示字串

主旨列需要識別「這封信屬於哪一門課、哪一期」。成人矯正班的既有文案在報名通知用期數（`成人矯正班第36期`）、在開課通知用組別（`發音聽力矯正課成人班–52100組`），兩者指向同一個班期。我們評估過統一成單一識別碼，最後決定保留兩份既有設計，因此**梯次名稱不是一個欄位，而是兩個**。

## Considered Options

- **統一成單一識別碼**（建議過但未採用）：兩封信都用 `成人矯正班第36期`。優點是學員在報到時已經打過這串字，開課時能立刻對應；`52100組` 只出現在主旨列、正文從未使用。缺點是必須放棄開課通知的既有主旨設計。
- **保留兩個字串**（採用）：兩封信各自維持原有的主旨寫法。

## Consequences

- 後端必須為每個班期儲存**兩個**顯示字串，課務也要維護兩份。這兩個欄位長得很像但不可互換，是容易被誤合併成一欄的地方。
- 學員先收到「成人矯正班第36期 報名成功」，數週後收到「發音聽力矯正課成人班–52100組 請加入課程群組」，可能無法確認是同一個班期。若日後接到相關客訴，這是第一個該回頭檢視的決定。
- 兒童課程不受影響：其梯次名稱即課程名稱，兩封信共用同一個值。
